# dotfiles
Various user settings symlinked to my home directory using [Stow](https://www.gnu.org/software/stow/).

## Usage
### macOS
1. `brew install stow`
1. `stow -t ~ git`
1. `stow -t ~ zsh`
1. `stow -t ~/Library/Application\ Support/Code/User code`
