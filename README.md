# dotfiles

This is a repository for my user settings. It's the first thing I clone whenever I buy a new computer or refresh my existing one. The repository is named `dotfiles` by convention—you may notice [some other developers](https://github.com/tobi/dotfiles) have a `dotfiles` too.

If you are a budding software developer, you should consider making one too! A tech recruiter worth their salt will see a `dotfiles` repo as a good sign.

## How to use this repo

1. Install [brew](https://brew.sh)
1. `brew install stow`
1. `stow -t ~ git`
1. `stow -t ~ zsh`
1. `stow -t ~/Library/Application\ Support/Code/User code`
